## 3. Corrigir Vercel e a segurança do webhook

8. Confirme o projeto **existente** `sdr-japa-sushi`, conectado à `main` do repositório correto, e a URL de produção `https://sdr-japa-sushi.vercel.app`. Verifique `Framework: Other`, pasta raiz, `api/manychat.js` como função única, `data/**` incluído, variáveis em **Production** e deploy do commit esperado. Não exponha os valores de variáveis secretas.
9. O relatório identificou um incidente: `WEBHOOK_SECRET` foi configurado como o **texto de um comando Node**, em vez do resultado aleatório do comando. Trate o segredo antigo como comprometido. Durante janela de manutenção, gere **novo valor** com gerador criptográfico, por exemplo executando localmente `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`. Guarde somente em local protegido. **Nunca cole o comando como valor da variável. Nunca mostre ou grave o segredo no chat, no GitHub, no relatório ou no log.** Atualize o mesmo valor em `WEBHOOK_SECRET` da Vercel Production e no cabeçalho privado `x-webhook-secret` do Dynamic Block ManyChat, minimize o intervalo de desencontro e faça redeploy. Se não houver acesso autorizado aos dois sistemas, interrompa a rotação e registre essa pendência; nunca troque um lado sem planejar o outro.
10. Confira `OPENAI_API_KEY` existente, `OPENAI_MODEL=gpt-4o-mini` ou modelo validado, `OPENAI_TIMEOUT_MS=8000`, `store:false` e a palavra `json` no input quando `text.format.type=json_object`. Não crie outra chave sem necessidade. Faça teste interno de saudação que realmente percorra a OpenAI e confira os logs, não só o HTTP 200 do webhook: o código pode devolver fallback 200 mesmo se a OpenAI falhar. Se ainda houver HTTP 400, investigue a mensagem curta da API e o nome do modelo sem copiar dados de clientes.
11. Valide: `GET /api/manychat` deve indicar `app_version=1.3.1`, catálogo e grupos; POST sem token ou com token falso deve retornar **401**; método não permitido **405**; POST autenticado nos modos padrão e `?mode=dynamic` deve funcionar. A resposta dinâmica deve ter `version=v2`, `content.type=instagram`, campos e botões nativos válidos. Nunca use o endpoint GET como prova única de funcionamento.
